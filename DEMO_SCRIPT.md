# Five-minute demo script

All data in this script is fictional. The same steps are in the app under **Demo Guide**, with links.

**Before you present**

1. Open the site (or `npm run dev` locally).
2. Click **Reset data** (top right) so the mock data is in its original state.
3. Set the role (bottom left) to **Ian · Partnerships**.
4. This build never calls a model. When "Simulated pass" appears, say that the analysis is a mock fixture.

| Time | Say | Do |
|---|---|---|
| 0:00–0:30 **Problem** | "We have bank conversations. Deals stall because five teams work from scattered notes and unverified assumptions." | Overview: readiness dial, four numbers, table. |
| 0:30–1:30 **Input** | "This is where an opportunity comes from and what we know after one call." | *(Optional, 15s)* Pipeline Intake → Load mock attendee list → expand a row → Promote. Then open **Northstar** → show notes → **Analyze opportunity**. |
| 1:30–2:30 **Readiness** | "The score is the share of ten criteria with evidence. It is not a chance of signing." | Read "How this was determined". Expand the top blocker (evidence, owner, next action). Open the unknown "Cross-bank 24/7 settlement support is unverified". |
| 2:30–3:30 **Multiplayer** | "Commercial wants cross-bank. Engineering wants internal transfers. The AI does not pick. A person does." | Role → **Engineering**. Scope disagreement → "Adopt: Proposed resolution" → rationale → **Record decision**. Role → **Eran · Commercial** → **Approve**. Refresh the browser (or do the approval in a second tab). **Re-run analysis** → "What changed: v1 → v2". |
| 3:30–4:30 **Deliverables** | "The brief says only what the record supports. An agreement comes only from an approved template." | Pilot Package → **Generate draft brief** → download `.md`. Point at the locked MOU panel. Open **Lakeshore** → Analyze → Pilot Package → **Load fictional demo template** → role **Legal** → **Mark approved** → **Populate agreement draft** → point at `[TO CONFIRM]`. |
| 4:30–5:00 **Value** | "Everything on this card was counted from what we just did." | Overview: numbers and activity feed have moved. Team Review → Audit trail. |

**Expected numbers:** Northstar scores 35, then 40 after the scope decision and re-run. Lakeshore scores 30. Harborlight (75), Falcon Ridge (40) and Cedar Ridge (10) are pre-analyzed so the Overview has range.

**Optional safety beat (20s):** Northstar → Discovery → Edit notes → "Append a sample injection line" → Save → Re-run. A red banner flags the line; stage, score and pricing do not change.

**Do not say:** any CTS price, any promotional offer, any integration depth, or any time saved unless you call it illustrative.
